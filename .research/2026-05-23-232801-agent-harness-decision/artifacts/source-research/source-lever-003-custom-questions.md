# Lever — Custom Application Questions Research

Sources: Lever help docs, JobWizard blog

## Custom Question Types Supported by Lever

| Type | Notes |
|------|-------|
| Single line text | Free-form short answer |
| Long text | Multi-line essay / textarea |
| Dropdown | Single select from predefined list; supports auto-screening rules |
| Multiple choice / Checkbox | Multi-select; supports auto-screening rules |
| Yes/No | Boolean; supports auto-screening rules |
| File upload | Up to 100MB; used for cover letters, portfolios, writing samples |
| Link / URL | For LinkedIn, GitHub, portfolio URLs |

Auto-screening rules can be applied to: multiple choice, checkbox, dropdown, and file upload question types.

## Scope of Custom Questions
- Global application form questions: apply universally to all jobs at the company (configured in Settings > Job Site > Application Form)
- Per-posting custom questions: added at the individual job level; override or supplement global questions

## Typical Custom Question Examples on Lever

### Work Authorization / Compliance
- "Are you legally authorized to work in the [country]?"
- "Will you require visa sponsorship now or in the future?"

### Role-Specific Short Text
- "What is your expected salary/compensation?"
- "When would you be available to start?"
- "Describe your experience with [specific tool/framework]"

### Open-Ended Essays (biggest agent effort)
- "Why are you interested in this role at [company]?"
- "What is a project you're most proud of?"
- "Tell us about a time you handled ambiguity"
- "What does [company's mission] mean to you?"

### File Uploads
- Cover letter (sometimes required via file upload question)
- Writing sample
- Design portfolio
- GitHub repo link (sometimes as link-type question)

## Key Difference from Greenhouse
Lever's form has two tiers: (1) universal questions configured site-wide and (2) per-job custom questions. The universal ones (name, email, phone, location, LinkedIn) are always present. Custom per-job questions are the variable tail.
