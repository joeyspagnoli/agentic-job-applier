# Source: Simplify Copilot Coverage on Taleo

## Key Findings

### Simplify's Coverage on Taleo
Reddit r/recruitinghell (primary community source):
> "It definitely helps a lot on sites like Workday, Taleo, Lever, Greenhouse. It does a fairly decent job of auto-inserting your background and education."

Taleo is **explicitly listed** as a platform where Simplify provides autofill. This makes Taleo better-covered than iCIMS from Simplify's perspective.

### What Simplify Can Fill on Taleo
When the candidate is already logged in (account exists) and the application form is active:
- Contact info fields (name, email, phone, address)
- Work experience fields (employer, title, dates, descriptions)
- Education fields (school, degree, graduation year)
- Some dropdown fields (country, state)

### What Simplify Cannot Fill on Taleo
- The account creation step itself
- Email verification step (requires external email access)
- Employer-configured custom screening questions (free-text essay questions)
- EEO/voluntary disclosure dropdowns (inconsistent coverage reported)
- File upload fields (the resume upload itself is a browser file picker, not a text field)

### Critical Gap: Per-Company Accounts
Even though Simplify helps with Taleo forms, the **per-company account requirement** means:
- First application to Company A using Taleo: agent must create a new account
- Subsequent application to Company B also using Taleo: must create ANOTHER new account
- There is no "universal Taleo login"

This means account creation friction hits on EVERY new company, not just the first time Taleo is encountered.

### Simplify's Overall Limitation
From the 2026 review analysis: Simplify is a Level-1 auto-apply tool (fills fields, user still clicks Submit). For Taleo specifically:
- Pre-existing login: Simplify can fill ~60–70% of fields
- First-time account creation: Simplify does not help; agent must handle the account wall independently
