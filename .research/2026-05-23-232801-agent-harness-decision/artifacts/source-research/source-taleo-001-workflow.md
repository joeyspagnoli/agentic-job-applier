# Source: Taleo Apply Form Fields and Steps

## Key Findings

### Landing Behavior
Taleo (Oracle Talent Acquisition Cloud / Oracle Taleo Enterprise Edition) job postings typically land on a **Career Section** page with job details. The "Apply" button is present on the job detail page. Clicking it leads to an **account creation / login wall** in virtually all standard configurations.

From TCNJ Taleo guide (PDF, official user documentation):
> "You will need to click the New User button to create a username and password. This is not your TCNJ single sign on. This is separate and for Taleo only."

### Account Creation Flow
- Required: **YES** — Taleo Enterprise Edition requires a candidate account before applying
- The account is **site-specific**: each company's Taleo deployment has its own database; creating an account at Company A does NOT carry over to Company B even though both use Taleo
- Steps: click "New User" → enter email, create password → optional: enter basic contact info → land on Career Home dashboard → select job → begin application

### Email Verification
Oracle Taleo Enterprise Edition added **Candidate Email Address Verification** (Release 17, 2018). Many employers have this enabled. This means:
- After account creation, a verification email is sent
- Some employers require email verification BEFORE the application form loads
- This is an **automation blocker** — the agent would need to check the email inbox to retrieve the verification link

### Multi-Step Application Structure (typical Taleo Enterprise flow)
Taleo Career Sections are employer-configured but follow a standard block structure:

1. **Login / Account Creation** — email, password
2. **Résumé** — upload or paste; Taleo parses into structured fields
3. **Candidate Profile** — contact info, address, phone, work authorization
4. **Work Experience** — employer, title, dates, description (may pre-fill from parse)
5. **Education** — institution, degree, GPA (may pre-fill)
6. **Certifications / Skills** — free-text or multi-select
7. **Screening Questions** — employer-defined; may include disqualifying questions
8. **EEO / Voluntary Disclosure** — veteran status, disability, race/ethnicity (always at the end)
9. **Review & Submit** — "Submit" button

Total steps: typically 6–9 depending on employer configuration.

### Resume Parsing / Pre-fill
Taleo has a built-in resume parser. Supported formats:
- PDF (widely supported)
- DOCX / DOC
- RTF
- TXT

**Critical known issue**: Some Taleo instances reject PDFs with the error "The file type you selected cannot be uploaded for security reasons." This is a file-security configuration issue, not a format issue per se. The actual observed behavior:
- Standard PDF: usually accepted
- PDFs generated by certain LaTeX engines (especially large PDFs or non-standard character encoding): sometimes rejected
- DOCX format is more universally accepted across all Taleo instances

### Custom / Long-Form Questions
Yes — Taleo supports employer-configured essay questions with free-text text areas. These appear in the Screening Questions block and are NOT pre-filled. The agent must generate these responses.

### EEO / Voluntary Disclosure Layout
Always at the **end** of the application, before the final submit page. Typical fields:
- Gender (dropdown)
- Race/Ethnicity (dropdown)
- Veteran status (dropdown or checkbox)
- Disability status (checkbox or dropdown)

### Submit Button Text
Reports and Taleo documentation consistently show: **"Submit"** as the primary button label. Some employers configure it as **"Submit Application"**. The final page may also show "Finish" in some older Taleo Business Edition deployments.
