# Greenhouse — Simplify Copilot Coverage Research

Sources: Simplify help docs, review sites (ResumeHog, HirePilot, JobRight, RemoteJobAssistant), community reports

## What Simplify Fills on Greenhouse

Standard biographical fields from stored profile:
- First name, Last name
- Email
- Phone
- Location
- LinkedIn URL
- Work history (title, company, dates) — parsed and mapped from resume/profile
- Education (degree, school, graduation year)
- Skills (autofilled when field appears)
- Disability / EEO fields (toggleable in settings — can fill "decline to self-identify")
- Work Authorization (toggleable — stores user's saved answer)

Simplify's autofill settings list togglable fields:
`LinkedIn URL, Disability, Location, Phone, Education, Work Authorization, Salary`

## What Simplify Misses on Greenhouse

1. **Custom application questions** — Employer-configured questions are the #1 miss. These include:
   - Open-text essays: "Why do you want to work here?", "Describe a challenge..."
   - Salary expectations (free-text, not always filled even when toggled)
   - Start date
   - Referral/source (the "How did you hear about us?" dropdown — sometimes not matched)
   - Visa sponsorship specifics beyond yes/no
   - Portfolio URL if not stored in profile

2. **"How did you hear about us?" dropdown** — frequently missed or wrong value selected

3. **Cover letter** — Not generated by free Simplify; Simplify+ only (paid AI cover letter)

4. **Resume upload validation** — Simplify uploads the stored PDF, but if employer has specific format requirements it may not auto-select

5. **Multi-page form progression** — Simplify can auto-advance through pages (setting available) but occasionally stalls on page transitions

## AI-Assist for Custom Questions (Paid Only)
- Simplify+ ($39.99/mo) offers AI-generated answers to open-ended questions
- Free tier: no AI fill for custom questions — user must type manually
