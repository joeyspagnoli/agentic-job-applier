# Greenhouse — Custom Application Questions Research

Sources: Greenhouse support docs, jobpilotapp.com, notchresume.com

## Custom Question Types Supported by Greenhouse

Greenhouse supports the following answer types for custom application questions:
- **Short text** (single line)
- **Long text / essay** (multi-line)
- **Yes/No** (boolean, often used for knockout screening)
- **Dropdown** (single select from predefined list)
- **Attachment** (file upload, up to 500MB)
- **Checkbox** (multi-select)
- **Number**
- **Date**

## Typical Custom Questions Per Job
- Range: 0–12 per job posting; modal is 3–6 for tech companies
- Standard fields are the same across companies; custom questions are where applicants differentiate themselves

## Most Common Custom Question Examples

### Knockout / Screening (Yes/No)
- "Are you legally authorized to work in the United States?" (DOJ-approved phrasing)
- "Will you now or in the future require sponsorship for employment visa status?" (DOJ-approved)
- "Are you willing to relocate?"
- "Are you able to work on-site [location] X days/week?"

### Short Text
- Expected salary / compensation range
- Available start date
- Years of experience in [specific technology]
- "How did you hear about this role?" (sometimes as text, sometimes as dropdown)

### Long-form Essay (biggest time sink, highest agent effort)
- "Why do you want to work at [company]?"
- "Describe a challenge you've overcome and what you learned"
- "Tell us about a project you're proud of"
- "What excites you about this role?"
- "What is your approach to [X skill]?"

### Dropdown
- Education level
- Work authorization status
- Preferred work location (if multiple offices)
- Employment type preference

### File Upload
- Portfolio samples
- Writing samples
- Code samples
- Work products

## Privacy Configuration
- Questions can be marked "private" (visible only to admin, not hiring team)
- Questions can be marked required or optional

## Application Rules (Knockout Logic)
- Companies can create auto-reject rules tied to Yes/No or dropdown answers
- Example: answer "No" to work authorization → auto-reject before human review
