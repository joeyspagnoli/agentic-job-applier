# SmartRecruiters — Simplify Copilot Coverage Research

Sources: Simplify docs, review sites, Chrome Web Store reviews

## Simplify Support for SmartRecruiters
- SmartRecruiters is listed as a supported platform in Simplify's documentation
- "Works across more than 20,000 career pages and popular Applicant Tracking Systems like Workday, Greenhouse, Lever, iCIMS, Taleo, and SmartRecruiters"

## What Simplify Likely Fills on SmartRecruiters

Standard biographical fields:
- First Name, Last Name
- Email
- Phone
- Location / Place of Residence
- Work history (mapped to Experience section)
- Education
- Resume (file upload)
- Work Authorization (stored answer)

## What Simplify Misses on SmartRecruiters

1. **Custom screening questions** — Primary miss, same as all ATS platforms
   - Per-job questions that are unique to each employer
   - Open-text "Message to Hiring Manager" field (not generated by free Simplify)

2. **Multi-step form navigation** — SmartRecruiters often has multi-step applications (step 1: basics, step 2: experience, step 3: questions)
   - Simplify has a "multi-page form handling" setting that auto-progresses, but may stall
   - Agent may need to click "Next" between steps

3. **"I'm Interested" button trigger** — This is NOT a form field; Simplify's autofill is triggered AFTER the form appears. The agent must click "I'm Interested" to open the form first, then trigger Simplify.

4. **Message to Hiring Manager** — If enabled as required, this is a free-text field Simplify cannot generate (free tier); needs agent or user input

5. **Easy Apply vs. Standard form detection** — When Easy Apply is enabled for a specific platform (LinkedIn, etc.), the flow differs from the native SmartRecruiters form. Simplify behavior may differ.

## SmartRecruiters-Specific Complexity
- The "I'm Interested" → form-expand → fill → submit flow requires the agent to recognize that Simplify's autofill button will only appear AFTER the form is revealed
- Agent must handle the two-stage click: (1) "I'm Interested" / "Apply Now" to reveal form, (2) trigger Simplify, (3) fill remaining fields, (4) click Submit
